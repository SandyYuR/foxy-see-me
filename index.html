主题文件
文件名为主题的 name 字段（非法字符百分号转义）+ .json，放置于 <外部存储>/foxy/frontend/themes/（精确路径 Android/data/com.fxliang.foxy/files/foxy/frontend/themes/）。
注意：light / dark 是两套配色槽位，与预览右上角的深浅开关不是一回事。 key_border_enabled / key_stroke_enabled / show_swipe_hints* 都是 App 的全局设置（不在主题 JSON 里），已移到预览键盘的滑杆行上。
建模边界：预览键盘只画键面，不含 App 的候选栏 / 工具栏。 因此 candidateBarColor、accentColor（工具栏选中态）等字段在预览里看不到效果 —— 它们只影响候选栏与工具栏，不是没生效。
