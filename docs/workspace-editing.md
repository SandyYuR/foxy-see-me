# 编辑工作区与草稿恢复

更新日期：2026-10-26。

布局、弹出菜单、主题、符号等文件入口仍位于各自功能页的文件操作区。全局顶栏不提供布局专用导入入口；绿色保存状态与标题下方说明位于同一行右侧。

## 编辑按键

中央工作区和右侧属性窗宽度在原基础上增加 5%。桌面属性窗默认显示，与左侧预览等高；下方标签页保持 18px 间距。未选按键时，属性窗的分栏收起且不可展开；用户可以手动关闭窗口，再点击预览键重新打开。

点击预览键时在右侧显示其属性；点击下方行区段或网格里的键时，打开原有的大弹窗。手机未选键时，空属性窗位于预览下方；选键后展开底部编辑面板，避免默认浮层遮挡预览。

标签、图标、宽度权重和四向手势优先显示；字号、状态、颜色、变体和原始 JSON 保留在折叠区。编辑手势或重建字段区时保留原滚动位置，不把整个手势区移到表单开头。

点击“上滑”等方向，直接展开动作控件。修改仅影响草稿预览，点“应用”才写入文档，一次应用产生一次撤销记录。切换按键、布局或功能页时，有修改才提示“应用并继续／放弃并继续／继续编辑”。取消不产生新的文档修改。

横屏／分体等预览模式改变时，属性窗保持打开：原选择失效则显示禁用空面板，未应用草稿单独暂存，重新选择相同文件和位置的按键后继续编辑。只把键盘焦点移到属性输入框、手势控件或预览开关不会取消选择。点击键盘空白处可以取消选择。

布局编辑、按键定义、动作与宏、弹出菜单、主题和符号面板的主分栏均默认展开。这与未选键时的右侧禁用分栏是两套独立状态。

“发送按键（经过 Rime）”与“直接输入文字”用途不同。普通输入法按键应使用 Rime 引用或按键事件；文字动作直接上屏。已有 `text`、`commit`、临时切换布局和复杂 JSON 保留原有语义。

默认只修改当前放置位置。“编辑共享定义”单独显示入口与当前工程引用数；局部覆盖可能使某些引用不受共享修改影响。未加载文件的引用无法统计。

恢复继承是删除覆盖字段，显式清除保留相应 `null` 语义。候选属于独立 popup 文件，因此按键面板提供跳转入口，不在可取消的按键草稿中混入立即提交的候选编辑。移动、删除和另存为定义可通过“更多操作”进入原有编辑窗口。

## 本地缓存

- 已应用的布局、popup、主题、符号、文件名和导入包的共享定义上下文保存在本地。
- 未应用的按键、手势、按键原始 JSON，以及布局、popup、主题、符号页的 JSON 文本分别缓存。JSON 没有写完也能恢复。
- 当前页签、模拟状态、折叠状态和滚动位置一起恢复。按键草稿只有在文件与原始位置匹配时才自动重开，不会自动提交。
- 页面分栏按固定标识保存开合状态，不按整页元素顺序恢复。旧版顺序数组会被忽略，页面主分栏恢复初始展开；文件和未应用草稿继续保留。
- 按键状态变体、popup 候选窗口可以恢复为可继续编辑的窗口。其余高级窗口的输入以恢复记录保留，用户可以展开复制；不会悄悄丢弃原文或自动点击保存。
- 绿色“草稿已保存到浏览器”只表示本地缓存成功。失败时显示红色提示，用户仍可在所属文件页导出备份。
- 缓存不上传服务器，也不会写入 Foxy 文件。它不跨浏览器或跨站点同步；清除站点数据、使用无持久化存储的环境或改变离线文件位置可能使原缓存不可用。

“修改尚未导出”和“与最近生成的下载一致”按文件展示。网页能确认生成下载内容，不能确认文件是否已保存到手机目录。未应用的布局 JSON 在导出前会明确提示处理方式。

字体二进制沿用原有约定，不缓存；刷新后需要重新选择字体文件。撤销历史仍以当前页面会话为范围；恢复内容不会自动恢复完整历史栈。

## 还原默认

“还原默认”位于绿色保存提示之后，一次点击恢复初始布局、预览、配色和编辑状态。操作前先保存一份本地备份，再只清除本编辑器的草稿与网页配色设置；不清理同站点的其他存储。

“撤回还原”恢复备份中的文件和未应用草稿，并交换保存还原后产生的内容。若浏览器无法写入备份，操作会停止并提示，避免清除后无法找回。此备份不包含未缓存的字体二进制。

## 页面说明文字

日常界面只解释作用、操作、文件位置以及容易误解的区别。主题文件卡片保留配色联动和导出使用方式两句说明；源码文件名、尺寸常量、渲染分支等依据留在[主题预览实现记录](theme-preview-implementation.md)和代码注释里。颜色字段名和原始 JSON 入口继续保留，方便精确编辑。

## 实现与验证

保持纯前端、零构建、可直接打开 `index.html` 的架构。新职责分为：

| 模块 | 职责 |
| --- | --- |
| `edit-session.js` | 草稿会话、目标定位、提交校验、网格落点提案 |
| `key-editor.js` | 兼容弹窗和属性面板共用的按键表单 |
| `gesture-editor.js` | 共用手势控件和序列化，内联与弹窗入口 |
| `workspace.js` | 属性面板、离开守卫、保存状态、刷新恢复 |
| `workspace-reset.js` | 一键还原、还原前备份与撤回 |

草稿始终通过显式 profile/scope 编译，不临时替换全局文档。正式修改继续通过 `FE.mutate` 和统一撤销栈；新校验只阻止本次新增错误，不阻塞对已有错误文件的修复。

工作区浏览器测试使用本机 Edge/Chrome 的隔离配置，覆盖真实刷新、焦点、常用手势、取消与撤销、未完成 JSON、状态变体、候选窗口、存储失败、窄屏和触摸事件。兼容弹窗的宏引用及 `switch_layout_once` 导出往返由原有冒烟继续验证。

测试中的缩小可视高度是软键盘遮挡的近似检查；没有在 Android 真机安装 APK，因此不能代替真机输入法与软键盘验证。多选、批量粘贴外观/手势和整体主题页重构仍属于后续轮次。
