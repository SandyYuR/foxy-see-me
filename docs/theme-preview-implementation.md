# 主题预览实现记录

更新日期：2026-10-26。此文档保存从用户界面移出的维护依据，不作为普通编辑流程的操作说明。当前数据规则仍以 AGENT.md、布局 skill 和可执行契约为准。

## 主题文件与预览范围

主题导出名称由主题 `name` 生成；特殊文件名字符通过既有编码函数处理。设备目录是 `Android/data/com.fxliang.foxy/files/foxy/frontend/themes/`。

主题浅色／深色使用 `light`、`dark` 两个独立槽位。`state.themeSlot`、预览 `pt-theme` 与主题页 `th-slot` 双向同步。旧界面文字“预览深浅与槽位不是一回事”已不适用于目前实现。

边框、描边、滑动提示、圆角和间距模拟的是 App 全局外观设置，不写入布局或主题 JSON。网页配色独立于键盘主题。

## 工具栏

`toolbar-preview.js` 的历史依据来自 App 的 `os.java`、`w20.java`、`mf.java`：工具栏 chip 使用 40dp 行高、12dp 圆角、3dp 间距、18sp 字号、10dp×2dp 内边距。dp 换算统一由 `FE.kbDp` 完成。

工具栏容器按边框状态选择 `altKeyboardColor` 或 `candidateBarColor`；chip 底色为 `candidateBackgroundColor`，默认文字／图标为 `toolTextColor`，激活态使用 `accentColor`。能够激活的工具按钮集合继续由现有逻辑限定，不把“显示出来”当成“激活”。

图标按显式文件名映射。`keyboard_tools` 与 `theme` 代表同一个主题按钮，去重并复用图标；输入法开关使用“中文／西文”文字。全部按钮排列在横向滚动轨道中，两端渐隐仅提示还有内容。

图标自带实色时原样绘制，全单色图标才随主题染色。工具栏图标和字体只参与预览，不导出到 Foxy 文件。字体缺字检查依据 cmap；字体二进制不保存到本地草稿。

## 颜色与气泡

状态色、当前按键颜色、主题键类型颜色、主题整体颜色有固定优先级。方向提示色存在逐层回退规则，统一使用 `color-source.js` 的解析结果，不在界面另造合并逻辑。用户只需看当前色值、来源和清空后的结果。

气泡由主题 `popupTextColor` 与 `popupBackgroundColor` 决定，布局键颜色不改变它。当前 App 的历史核对未找到 `popupBorderColor` 对气泡的有效绘制用途，因此预览不画该边框，界面只提示“当前版本不显示气泡边框”。气泡几何为 6dp 圆角、44dp 高、24sp 字号，并受原有字号上限约束。

## 符号面板

外部符号文件需要在 Foxy 的符号布局设置中明确选择；仅放置同名文件不会覆盖内置数据。`multiLine` 开启时每行一项、高度随内容调整；关闭时使用紧凑格子，长条目会等比缩小。

具体解析规则、兼容性检查和反编译定位仍保留在对应模块的代码注释中。此次文案精简不修改文件格式、颜色优先级、图标规则或动作含义。
