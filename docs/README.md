# foxy-editor 文档索引

这里是 `foxy-editor` 的用户与维护文档入口。项目本身仍然是一个可以直接打开的纯前端页面；`docs/` 不参与运行时构建，只负责把当前入口、历史决策和维护依据分开保存。

## 先看什么

| 读者 | 建议入口 | 用途 |
| --- | --- | --- |
| 普通用户 | [项目简介与使用说明](../README.md) | 了解编辑器能做什么、如何加载示例、如何导出到 Foxy |
| 代理 / AI | [AGENT.md](../AGENT.md) | 改代码前必须注入的硬约束、测试命令和同步规则 |
| 想了解为什么这样实现 | [项目历史与决策记录](history/project-history.md) | 查看原始任务、历次功能演进、取舍原因、已修复问题和测试证据 |
| 需要核对文件格式 | [skills/](../skills/) | 查看 `SKILL.md` 与 JSON Schema；格式规则以这里为准 |

## 文档职责

- `README.md` 只介绍当前产品、快速上手、当前支持范围和导航，不记录逐轮改动历史。
- `AGENT.md` 只给代理提供改动前需要立即知道的规则，不承担项目编年史。
- `docs/history/project-history.md` 保存从原有 README/AGENT 中整理出的历史材料。它包含决策的背景和证据，但其中的历史叙述不是新的运行时规范；当前规范以源码、`skills/*.schema.json`、测试和 `AGENT.md` 的硬约束为准。

- 解析、校验、编译和预览：见[核心数据与预览演进](history/project-history.md#3-核心数据解析校验与预览演进)。
- 网格、分体、横屏和移动端问题：见[几何与响应式预览](history/project-history.md#4-几何与响应式预览)。
- 对话框、颜色、主题和符号面板：见[编辑器界面与主题功能演进](history/project-history.md#5-编辑器界面与主题功能演进)。

## 记录口径

历史文档尽量保留原文中出现过的提交号、日期、路径、命令、测试数量和实测数字。某个数字如果只代表旧阶段，会明确标为“历史基线”；不能把历史数字当成当前实现状态。当前改动前需要执行的命令和当前基线，以 `AGENT.md` 开头的规则为准。
